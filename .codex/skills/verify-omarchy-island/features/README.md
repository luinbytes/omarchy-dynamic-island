# Omarchy Island feature map

The map covers the independent plugin's activity foundation and planned visual behavior.

- [Activity contract](activity-contract.md) covers state, validation, expiry, and symbolic actions.
- [Quickbar anchor](quickbar-anchor.md) covers the hidden bar widget and planned renderer.
- [Live activity publishers](live-activity-publishers.md) covers planned activity sources.

Install this repository as a user plugin. Runtime evidence requires a disposable Omarchy session, not host source changes.
